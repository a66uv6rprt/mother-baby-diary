# 肝病早诊早治，艾滋共治共防—— 暨大附一院感染科门诊12 月公益筛查及健康宣教活动公告

> 更新时间：2026-09-17 (UTC+8)

为积极响应世界卫生组织 “2030年消除病毒性肝炎” 的全球公共卫生目标，落实天河区关于病毒性肝炎早预防、早诊断、早治疗的工作要求，切实保障市民肝脏健康，**暨南大学附属第一医院感染科肝病门诊定于2025 年12月1日起，开展为期一个月的 “消除肝炎，即刻行动” 公益筛查与健康宣教专项活动。**

同时，2025年12月1日为第38个 “世界艾滋病日”。根据《广州市公共卫生委员会天河区专责小组办公室转发关于做好 2025年 “世界艾滋病日” 主题活动的通知》部署，结合我院艾滋病防治工作职责，围绕 “社会共治，守正创新，终结艾滋” 宣传主题，同步开展 “世界艾滋病日” 主题宣传活动，旨在深化全社会对艾滋病防治工作重要性与长期性的认知，倡导各界协同履行防治责任，探索创新防治举措，推动艾滋病防治工作高质量发展。现将活动相关事宜公告如下：

**活动亮点****01**
便捷免费

提供乙肝表面抗原、丙肝抗体快速筛查服务，检测结果现场出具，全程无任何费用。

**0****4**
先锋引领

党员医护人员主动担当，以先锋模范作用践行医者使命，保障活动高效开展。

采用 “集中筛查 + 健康讲座 + 常态化筛查点 + 宣传资料派发” 多维模式，满足不同人群参与需求，提升活动覆盖面与可及性。

**活动安排****（一）**

**1. 时间：**每日上午9:30-11:30

免费快速筛查：开展乙肝表面抗原、丙肝抗体检测；

专题健康讲座：

**三**
**重点筛查人群**

为确保筛查工作精准有效，建议以下人群优先参与本次活动：

1. 未进行过乙肝、丙肝病毒检测者；

2. 有肝炎家族遗传史或与肝炎患者存在密切接触史者；

3. 1993 年前有输血史或使用血制品史者；

4. 有不安全注射、纹身、穿耳洞等高危行为者；

5. 肝功能检查结果异常且原因未明确者；

6. 需了解艾滋病防治知识的市民群众。

**四**
**参与方式**
活动期间，市民无需提前预约，可直接前往上述指定地点参与免费筛查及咨询。

**五**
**温馨提示**
