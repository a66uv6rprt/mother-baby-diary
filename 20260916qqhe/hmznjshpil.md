# 一等奖！柳人医在广西第三届急诊住培医师“病例分享”比赛中获佳绩

> 更新时间：2026-09-16 (UTC+8)

在近日举办的第三届急诊住培医师“病例分享”比赛中，柳人医急诊科专业基地住培医师**戴筱璇**凭借扎实的临床诊疗能力、缜密的病例分析思维及出色的学术表达，在激烈竞争中脱颖而出，斩获一等奖。

 比赛中，戴筱璇以**“无声的心脏、沸腾的战场”**为主题展开病例分享。其报告主题鲜明、亮点突出、质量精湛，通过一例真实病例，全面展现了扎实的临床功底与卓越的学术素养——从诊断难点突破到急救规范执行，从个性化治疗方案制定到 “层层深入、抽丝剥茧” 的临床思维过程，均体现出专业深度与急救处置能力。

 该报告在临床思维严谨性、教学价值启发性、人文关怀渗透性及案例创新性与典型性等核心评审维度，均获高度评价。

 备赛期间，基地高度重视，导师们从病例的筛选与深度挖掘、演讲框架的反复打磨，到专业知识的查缺补漏、演讲技巧的逐字雕琢，再到模拟演练的严格要求与临床心态的细致疏导，进行了全方位、精细化指导。

 近年来， 医院始终将住院医师规范化培训置于重要位置，严格遵循国家培训标准，以“六大核心胜任力”为纲领，系统性提升住培医师综合素质。

 围绕这一培养目标，医院创新实施导师制精准带教，常态化开展专项培训讲座，持续提升住培医师综合岗位胜任力。而急诊专业基地学员的此次夺冠，正是这一系统性培养成果的有力印证。

医院将持续深耕住培工作，不断完善培养体系，为医疗卫生事业输送更多高素质人才。

**急诊科专业基地简介**

柳州市人民医院急诊科是国家首批住院医师规范化培训专业基地，肩负桂中地区急危重症救治的核心使命。作为区域急救医学中心、自治区临床重点专科建设单位，专业基地集医疗、教学、科研 三位一体，构建“急救一体化”创新体系，现为中国创伤救治联盟建设单位、国家急诊质控中 心哨点医院、广西首个动物致伤防治示范基地 等13个国家级/省级平台及实验室，涵盖创伤、中毒、ECPR 等特色亚专科方向。2024年获柳州市卫生健康委“登高计划”培育国家级临床重点专科建设项目。

**一 、学科实力**

年急诊量突破20万例次，院前出诊量近万次，居区域首位。配备国际领先的急救设 施，包括ECMO(体外膜肺氧合)、CRRT(连 续肾脏替代治疗)、REBOA (复苏性主动脉球 囊阻断术)等先进生命支持系统，创新开展复 苏性主动脉球囊阻断创伤复苏、ECPR 等前沿 技术，急危重症救治成功率处于区内领先水 平。依托急诊病房、急诊监护室、急诊手术室 和复合手术室等全链条救治单元，为心脑血管 急症、多发伤等患者提供“黄金一小时”精准救治疗。

**二、教学体系**

现有博士5人、硕士24人、硕士研究生导师8人，配备18名师资与10位住培导师。构建“双导师制”培养模式，创建“三维督导”教学质量控制体系，通过科级督导员实时跟踪、教学 小组月度研讨、院级专家季度评估，确保教学 活动高质量开展。近三年住培结业考核通过率 持 续 保 持 1 0 0 % , 结 业 住 培 医 师 就 业 率 100%,并获用人单位高度评价。

**三、培养特色**

实施“分层进阶式”培养方案： 一年级夯实 急救基本功，二年级主攻亚专科方向，三年级 强化独立救治能力。创新开展医学情景模拟教 学，在珠江医学模拟案例大赛等赛事中斩获佳绩。推行“教学一临床一科研”三位一体培养， 住培医师可参与急危重症实验室课题，近三年 指导住培医师发表核心期刊论文12篇。
