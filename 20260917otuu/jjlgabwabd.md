# 【原创】好不容易养成的囊胚为什么不能用？

 临床上，选择囊胚培养的患者最期待的就是能多养几个好囊胚，但有些患者在胚胎第五天或者第六天来院时，却发现有些囊胚处理结果是**丢弃**，这是为什么呢？**好不容易养成的囊胚为什么不能用呢？**

随着辅助生殖技术被大家所熟知，越来越多的患者了解到囊胚移植有很多优势：

- 
囊胚移植**更符合生理情况**，具有**较高的着床和妊娠潜力**；

- 
可以有效降低移植胚胎数，进而**减少多胎妊娠**带来的并发症；

- 
对胚胎的**进一步筛选和修复**。

但也并不是只要长成囊胚就万事大吉了。

一般来说，囊胚培养是一个对胚胎进行**优胜劣汰**的筛选过程，只有质量好的胚胎才会最终发育形成囊胚，但是囊胚和卵裂期胚胎一样，也有优劣之分，也有一套完整的评分体系。

囊胚主要从**囊胚腔的扩张程度、内细胞团**以及**滋养层细胞**三方面进行评价。

首先根据**囊胚腔的大小和是否孵出**分为六期（以阿拉伯数字“1-6”表示），**数字越大表示囊腔体积越大，发育得越快**；

然后根据**内细胞团和滋养层细胞的数量和排列****情况**分别分为A、B、C三个等级，A代表最好，B次之，C质量最差，这样就有了我们看到的囊胚等级，例如AA，AB等。

**级别越高囊胚的质量越好，妊娠和着床的机率越大。**

- 3期以上，内细胞团和滋养细胞BB以上的称为**优质囊胚**；
- 3期以上，内细胞团和滋养细胞有一个B级以上的称为**可利用囊胚**。
- 2期以下或CC级的囊胚质量较差，评为**不可用囊胚**，移植这类囊胚妊娠率极低、流产率高，所以往往会被淘汰。

囊胚培养是整个试管周期中极具挑战的一项操作，因为要将受精卵**人工培育**至第五或第六天形成囊胚，这对实验室环境和胚胎学家要求极为严苛。
